# Mon Lac

Le Léman du jour en un coup d’œil : pour chaque plage, la température de l’eau, l’air, le vent et la bise,
avec un verdict simple pour la baignade (ou le bain d’hiver), le paddle et la voile. En plus : bars et restos
au bord de l’eau, loueurs d’activités nautiques, défi bain d’hiver avec historique, en français et en anglais.

Site : **https://xiff.github.io/Le-lac/** (futur domaine : monlac.ch).

## Comment ça marche

- **Le verdict** (`score.js`) : chaque activité reçoit une note de 0 à 3 (Non, Bof, Bien, Parfait) à partir de l’eau,
  de l’air, du vent, des rafales et de la météo. D’octobre à mai sous 15°, la baignade devient « bain d’hiver ».
  Le titre d’accueil vient de l’activité la mieux notée (ou orage, bise, journée terrasse), avec plusieurs phrases
  qui tournent à chaque affichage.
- **L’eau** : modèle Alplakes de l’Eawag (CC BY 4.0), valeur à 70 cm sous la surface devant chaque plage.
  Une tâche GitHub (`.github/workflows/eau.yml`, toutes les 3 h) écrit `eau.json`, `qualite.json`,
  les pages par plage et le sitemap.
- **La météo** : Open-Meteo, lue directement par le navigateur.
- **La qualité de l’eau** : analyses du canton de Genève, affichées seulement si elles ont moins de 30 jours ;
  sinon un lien en bas de page renvoie à la source (canton ou CIPEL).
- **Bars, restos, loueurs** : listes écrites à la main et vérifiées (`lieux.js`, `locations.js`).
  Le formulaire « un lieu manque ? » ouvre un ticket GitHub à relire avant ajout.
- **Hors ligne** : un service worker (`sw.js`) garde la dernière version pour l’ouvrir sans réseau.
- **Android** : `android/` contient de quoi générer l’app Play Store (Trusted Web Activity), voir `android/LISEZMOI.md`.

## Développer

```sh
python3 -m http.server 8765        # puis http://localhost:8765/
node --test *.test.mjs             # tests
node scripts/pages.mjs             # régénérer les pages par plage et le sitemap
```

Après une modification de l’interface, changer le numéro de cache dans `sw.js` (`lac-vNN`).
